# Sociedades de corretaje

Cómo funciona una casa de bolsa por dentro: el mercado de valores, la apertura de la cuenta, las órdenes, el libro de órdenes y el calce, la ruta de una orden, la compensación y la liquidación, la custodia, la plataforma, las emisiones y su colocación, las comisiones, el margen y el cumplimiento.

**Ver en línea:** https://aaramirez.github.io/corretaje/

Este repositorio solo tiene el sitio generado. El curso está en preparación: la tabla de contenido ya está publicada para revisión.
